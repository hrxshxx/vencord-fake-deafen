# FakeDeafen (Vencord userplugin)

Appear deafened (and optionally muted) to others in a voice channel while still hearing everyone.

## Install
1. Clone and set up Vencord: `git clone https://github.com/Vendicated/Vencord && cd Vencord && pnpm i`
2. Copy this folder to `src/userplugins/fakeDeafen/`
3. `pnpm build && pnpm inject` (or `pnpm buildWeb` for the browser extension)
4. Enable **FakeDeafen** in Settings → Vencord → Plugins

## Usage
- Toolbox → "Toggle Fake Deafen" (requires the VencordToolbox plugin)
- `/fakedeafen` slash command

> Client mods violate Discord's ToS. Use at your own risk.
